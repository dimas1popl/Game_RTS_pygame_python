Особенности

    Полноценное управление - движение во всех 4 направлениях

    Плавная анимация - разные анимации для каждого направления движения

    Параллакс-фон - повторяющийся фоновый рисунок
Установка и запуск
1. Клонирование репозитория
bash

git clone <URL репозитория>
cd <папка с проектом>

2. Установка зависимостей
bash

pip install pygame

3. Запуск игры
bash

python main.py

Управление
Клавиша	Действие	Направление
W или ↑	Движение вверх	↑
S или ↓	Движение вниз	↓
A или ←	Движение влево	←
D или →	Движение вправо	→
ESC	Выход из игры	-
